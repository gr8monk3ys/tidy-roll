# Screenshots Notes

You will need real screenshots for submission.

## Suggested screenshot set (minimum viable)

- Home: modes + month-by-month progress
- Session: swipe overlays (KEEP / DELETE)
- Summary: staged deletes + confirm button
- Albums: choose Remove vs Delete
- Bookmarks: grid + review
- Stats: settings + permission status

## Tips

- Avoid showing sensitive personal info.
- Use the same theme and wording across iOS/Android.
- Double-check the latest store device-size requirements before exporting.
